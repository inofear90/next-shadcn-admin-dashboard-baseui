## Active Theme Preset
This project uses the **Tangerine** preset (warm orange/amber tones).
See: `src/styles/presets/tangerine.css`

When creating new components:
- Use semantic tokens: `bg-background`, `text-foreground`, `bg-primary`
- Primary color = amber/orange family
- Do NOT hardcode hex values
- Reference existing components in `src/components/` as pattern
